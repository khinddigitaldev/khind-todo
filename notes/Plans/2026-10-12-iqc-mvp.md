# KHIND IQC MVP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn the `khind-todo` app into the KHIND IQC demo system described in the PRD (all P0 requirements), running on Vercel Hobby + Supabase Free with fictional data.

**Architecture:**
- **Supabase Postgres holds the rules.** Row Level Security and column grants decide who can read or write what. Security-definer SQL functions perform every status change (create, submit, return, approve, reopen, override). A trigger writes the append-only audit log.
- **Next.js 16 (App Router, Server Components and Server Actions) is a thin UI** over those rules. Pure TypeScript modules in `lib/iqc/` hold the live-UI logic (verdict, readiness, metrics, CSV, usage), each unit-tested with Vitest.
- **Cloud only:** database changes are migrations pushed with the Supabase CLI to the linked cloud project, and pgTAP tests run against it inside rolled-back transactions.

**Tech Stack:**
- Next.js 16.4.0, React 19.3, TypeScript, Tailwind 4
- `@supabase/ssr` 0.12.7, `@supabase/supabase-js` 2.117.3, Supabase CLI 2.120.0 (via `npx`)
- zod 4.6.6, exceljs 4.4.0, fflate 0.8.3
- Vitest 5, pgTAP

**Spec:** `notes/02 Spec.md` (PRD v2.1, approved 2026-10-12)

## Global Constraints

- **Cloud only.** Supabase project ref `nctqwmlrthwbqnliwyyo` (demo, **fictional data only**). No Docker, no local database.
- **Next.js 16 rules:** read `node_modules/next/dist/docs/` before Next-specific code (see `AGENTS.md`).
  - `cacheComponents` is on, so anything that reads cookies, `params` or `searchParams` must render inside `<Suspense>`.
  - `createClient()` already calls `await connection()`.
- **Keys:** only the Supabase **publishable** key is used anywhere. Never the secret key, and never a `NEXT_PUBLIC_` secret.
- **Sampling:** the sample size is computed **in the database only** (`sample_size_for`). The acceptance rule defaults to **c = 0** (Ac 0, Re 1) for every defect class.
- **Locking:** status changes happen **only** through SQL functions. Approved inspections can't be edited, only reopened by QA with a reason.
- **Photos:** only on NG checklist items or on lots whose verdict is Reject. Each photo is ≤ 200 KB (204,800 bytes), with at most 3 per NG item and 6 per inspection.
- **UI:** touch targets ≥ 44 px (`min-h-11`); English UI text.
- **Public repo:** no real KHIND suppliers, parts, people or inspections. Seed data uses names ending in "(Demo)".
- **Commits:** every commit message ends with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- **Windows commits:** write commit messages to a temp file and use `git commit -F <file>`. PowerShell here-strings don't pass through to git reliably.
- **Pinned CLI:** run the Supabase CLI as `npx supabase@2.120.0 …` (abbreviated to `npx supabase` below).

## Review Focus

1. **Lot size not covered by the sampling table** (gap between bands, 0, or larger than any band when the last band isn't open-ended). Expect a clear message naming the lot size, not a crash. *Tests: Task 2 (SQL `sample_size_for`), Task 8 (`validateBands`), Task 11 (editor blocks saving).*
2. **Autosave arriving after the inspection was submitted**, from a second tab or a slow network. The server rejects the write, and the form shows "This inspection is no longer editable". *Tests: Task 3 + Task 4 (RLS: 0 rows updated after submit), Task 13 (`saveDraft` returns `NOT_EDITABLE`; user check 6).*
3. **Submitting with gaps:** unanswered items, NG without a comment, no readings, more readings than the sample size, or defects above the sample size. Submit is refused with the full list. *Tests: Task 4 (SQL), Task 7 (`missingForSubmit`).*
4. **QA choosing Accept when the verdict is Reject, or approving their own inspection.** Both are refused by the database. *Tests: Task 4.*
5. **A deactivated user who is still signed in.** They lose all data access on the next request, and the app signs them out. An admin can't deactivate themselves. *Tests: Task 3 (RLS: deactivated sees nothing, admin cannot deactivate self), Task 9 (`requireProfile` → `/auth/signout`), Task 12 (user check 2).*

```sql
-- Sample size: computed by the database only ---------------------------------
create function public.sample_size_for(
  p_lot int, p_stage public.sampling_stage, p_type public.inspection_type default 'sampling'
) returns int language plpgsql stable set search_path = '' as $$
declare
  b public.sampling_bands;
  s int;
begin
  if p_lot is null or p_lot < 1 then
    raise exception 'Lot size must be at least 1';
  end if;
  if p_type = 'full' then
    return p_lot;
  end if;
  select * into b from public.sampling_bands
  where active and plan_source = 'KHIND' and p_lot >= lot_min and (lot_max is null or p_lot <= lot_max)
  order by lot_min desc limit 1;
  if not found then
    raise exception 'No sampling band covers a lot of %. Ask QA to update the sampling table.', p_lot;
  end if;
  s := case p_stage when 'tightened' then b.sample_tightened else b.sample_normal end;
  if s is null or s >= p_lot then
    return p_lot;
  end if;
  return s;
end $$;

create function public.touch_updated_at() returns trigger language plpgsql as $$
begin
  new.updated_at := now();
  return new;
end $$;
create trigger inspections_touch before update on public.inspections
  for each row execute function public.touch_updated_at();

create function public.inspections_resample() returns trigger
language plpgsql set search_path = '' as $$
declare
  t public.inspection_type;
begin
  if new.sample_override_reason is null
     and (new.qty_received is distinct from old.qty_received or new.stage is distinct from old.stage) then
    select inspection_type into t from public.parts where id = new.part_id;
    new.sample_size := public.sample_size_for(new.qty_received, new.stage, t);
  end if;
  return new;
end $$;
```

```sql
create function public.create_inspection(
  p_supplier_id bigint, p_part_id bigint, p_qty int, p_received_at timestamptz default now(),
  p_po text default null, p_do text default null, p_lot text default null

declare
  v_part public.parts;
  v_version bigint;
  v_id bigint;
begin
  if not public.has_role('inspector', 'qa') then
    raise exception 'Only inspectors and QA can start an inspection.' using errcode = '42501';
  end if;

  if not found then raise exception 'Part not found or inactive.'; end if;
  if v_part.inspection_type = 'none' then

  end if;
  if v_part.template_id is null then

  end if;

  returning id into v_id;

  insert into public.inspection_defects (inspection_id, defect_class)

create function public.inspection_verdict(p_id bigint) returns text
language sql stable security definer set search_path = '' as $$
  select case
    when bool_or(d.found is null) then null
    when bool_or(d.found >= coalesce(d.re, a.re, 1)) then 'reject'
    else 'accept' end
  from public.inspection_defects d
  left join public.sampling_acceptance a on a.plan_source = 'KHIND' and a.defect_class = d.defect_class
  where d.inspection_id = p_id
$$;

create function public.submit_inspection(p_id bigint) returns text
language plpgsql security definer set search_path = '' as $$
declare
  v public.inspections;
  missing text[] := '{}';
  n int;
begin
  select * into v from public.inspections where id = p_id for update;
  if not found then raise exception 'Inspection not found.'; end if;
  if v.inspector_id <> auth.uid() or not public.has_role('inspector', 'qa') then
    raise exception 'Only the inspector who owns this inspection can submit it.' using errcode = '42501';
  end if;
  if v.status not in ('draft', 'returned') then
    raise exception 'This inspection is already %.', v.status;
  end if;

  select count(*) into n from public.template_items ti
  where ti.version_id = v.template_version_id
    and not exists (select 1 from public.inspection_checks c where c.inspection_id = p_id and c.item_id = ti.id);
  if n > 0 then missing := missing || format('%s checklist item(s) not answered', n); end if;

  select count(*) into n from public.inspection_checks
  where inspection_id = p_id and result = 'ng' and coalesce(trim(comment), '') = '';
  if n > 0 then missing := missing || format('%s NG item(s) need a comment', n); end if;

  select count(*) into n from public.template_characteristics tc
  where tc.version_id = v.template_version_id
    and not exists (select 1 from public.inspection_measurements m
                    where m.inspection_id = p_id and m.characteristic_id = tc.id and cardinality(m.readings) >= 1);
  if n > 0 then missing := missing || format('%s dimension(s) have no readings', n); end if;

  select count(*) into n from public.inspection_measurements
  where inspection_id = p_id and cardinality(readings) > v.sample_size;
  if n > 0 then missing := missing || format('%s dimension(s) have more readings than the sample size', n); end if;

  select count(*) into n from public.inspection_defects where inspection_id = p_id and found is null;
  if n > 0 then missing := missing || format('%s defect count(s) not entered', n); end if;

  select count(*) into n from public.inspection_defects where inspection_id = p_id and found > v.sample_size;
  if n > 0 then missing := missing || 'defects found cannot be more than the sample size'; end if;

  if cardinality(missing) > 0 then
    raise exception 'Cannot submit: %.', array_to_string(missing, '; ');
  end if;

  -- Snapshot the acceptance numbers in force today.
  update public.inspection_defects d
  set ac = coalesce(a.ac, 0), re = coalesce(a.re, 1)
  from (select dc, sa.ac, sa.re
        from unnest(enum_range(null::public.defect_class)) dc
        left join public.sampling_acceptance sa on sa.plan_source = 'KHIND' and sa.defect_class = dc) a
  where d.inspection_id = p_id and d.defect_class = a.dc;

  update public.inspections
  set status = 'submitted', submitted_at = now(), return_comment = null,
      verdict = public.inspection_verdict(p_id)
  where id = p_id;
  return public.inspection_verdict(p_id);
end $$;

create function public.approve_inspection(
  p_id bigint, p_disposition public.disposition, p_concession_reason text default null
) returns text language plpgsql security definer set search_path = '' as $$
declare
  v public.inspections;
  v_verdict text;
  v_summary text;
  v_ncr text;
begin
  if not public.has_role('qa') then raise exception 'Only QA can approve.' using errcode = '42501'; end if;
  select * into v from public.inspections where id = p_id for update;
  if not found then raise exception 'Inspection not found.'; end if;
  if v.status <> 'submitted' then raise exception 'Only submitted inspections can be approved.'; end if;
  if v.inspector_id = auth.uid() then
    raise exception 'You cannot approve an inspection you performed.' using errcode = '42501';
  end if;
  v_verdict := public.inspection_verdict(p_id);
  if v_verdict = 'reject' and p_disposition = 'accept' then
    raise exception 'The system verdict is Reject. Choose concession, sort/rework or reject.';
  end if;
  if p_disposition = 'concession' and coalesce(trim(p_concession_reason), '') = '' then
    raise exception 'A concession needs a reason.';
  end if;

  update public.inspections
  set status = 'approved', approver_id = auth.uid(), approved_at = now(), disposition = p_disposition,
      verdict = v_verdict, reopen_reason = null,
      concession_reason = case when p_disposition = 'concession' then trim(p_concession_reason) end
  where id = p_id;

  if p_disposition <> 'accept' then
    select coalesce(string_agg(format('%s: %s found%s', d.defect_class, d.found,
                                      coalesce(' - ' || nullif(trim(d.description), ''), '')),
                               '; ' order by d.defect_class), 'No defects counted')
    into v_summary
    from public.inspection_defects d where d.inspection_id = p_id and d.found > 0;

    insert into public.ncrs (number, inspection_id, qty_affected, summary, disposition)
    values (public.next_number('NCR'), p_id, v.qty_received, v_summary, p_disposition)
    on conflict (inspection_id) do update set disposition = excluded.disposition, summary = excluded.summary
    returning number into v_ncr;
  end if;
  return v_ncr;
end $$;
```

```sql
-- Append-only audit trail. Nobody can edit it through the API (see 0300 grants).

create function public.audit_row() returns trigger
language plpgsql security definer set search_path = '' as $$
declare
  v_old jsonb := case when tg_op <> 'INSERT' then to_jsonb(old) end;
  v_new jsonb := case when tg_op <> 'DELETE' then to_jsonb(new) end;
  v_row jsonb := coalesce(v_new, v_old);
  v_inspection bigint;
  v_status text;
  v_changes jsonb;
begin
  if tg_table_name = 'inspections' then
    v_inspection := (v_row ->> 'id')::bigint;
    v_status := coalesce(v_old ->> 'status', v_new ->> 'status');
  elsif v_row ? 'inspection_id' then
    v_inspection := (v_row ->> 'inspection_id')::bigint;
    select status::text into v_status from public.inspections where id = v_inspection;
    if v_status is null then return null; end if;  -- parent draft being deleted
  end if;

  -- Skip autosave noise while a draft, but always log creation and status changes.
  if v_status = 'draft' and not (tg_table_name = 'inspections'
       and (tg_op = 'INSERT' or (v_old ->> 'status') is distinct from (v_new ->> 'status'))) then
    return null;
  end if;

  if tg_op = 'UPDATE' then
    select jsonb_object_agg(k, jsonb_build_array(v_old -> k, v_new -> k)) into v_changes
    from jsonb_object_keys(v_new) k
    where k <> 'updated_at' and (v_old -> k) is distinct from (v_new -> k);
    if v_changes is null then return null; end if;
  else
    v_changes := v_row;
  end if;

  insert into public.audit_log (table_name, row_id, inspection_id, action, changes, user_id)
  values (tg_table_name,
          coalesce(v_row ->> 'id', concat_ws(':', v_row ->> 'inspection_id', v_row ->> 'item_id',
                   v_row ->> 'characteristic_id', v_row ->> 'defect_class', v_row ->> 'plan_source')),
          v_inspection, lower(tg_op), v_changes, auth.uid());
  return null;
end $$;

revoke execute on function public.audit_row from public, anon, authenticated;

create trigger audit after insert or update or delete on public.inspections for each row execute function public.audit_row();
create trigger audit after insert or update or delete on public.inspection_checks for each row execute function public.audit_row();
create trigger audit after insert or update or delete on public.inspection_measurements for each row execute function public.audit_row();
create trigger audit after insert or update or delete on public.inspection_defects for each row execute function public.audit_row();
create trigger audit after insert or update or delete on public.attachments for each row execute function public.audit_row();
create trigger audit after insert or update or delete on public.ncrs for each row execute function public.audit_row();
create trigger audit after insert or update or delete on public.suppliers for each row execute function public.audit_row();
create trigger audit after insert or update or delete on public.parts for each row execute function public.audit_row();
```

```ts
import type { DefectClass } from "./types";

// Live verdict for the inspection form. The database computes the same rule
// on submit/approve (inspection_verdict) — that one is authoritative.

export type DefectCount = { defectClass: DefectClass; found: number | null; ac: number };
export type Verdict = "accept" | "reject" | "incomplete";

export function lotVerdict(defects: DefectCount[]): Verdict {
  if (defects.some((d) => d.found !== null && d.found >= d.ac + 1)) return "reject";
  if (defects.some((d) => d.found === null)) return "incomplete";
  return "accept";
}

export function isOutOfTolerance(value: number, min: number | null, max: number | null): boolean {
  return (min !== null && value < min) || (max !== null && value > max);
}

export function measurementResult(readings: number[], min: number | null, max: number | null): "ok" | "ng" | null {
  if (readings.length === 0) return null;
  return readings.some((v) => isOutOfTolerance(v, min, max)) ? "ng" : "ok";
}

export function reviewWarnings(input: { ngItems: number; ngMeasurements: number; totalFound: number }): string[] {
  if (input.totalFound > 0) return [];
  const warnings: string[] = [];
  if (input.ngItems > 0) {
    const s = input.ngItems === 1 ? "1 checklist item is" : `${input.ngItems} checklist items are`;
    warnings.push(`${s} NG but no defects were counted. Review before accepting.`);
  }
  if (input.ngMeasurements > 0) {
    const s = input.ngMeasurements === 1 ? "1 dimension is" : `${input.ngMeasurements} dimensions are`;
    warnings.push(`${s} out of tolerance but no defects were counted. Review before accepting.`);
  }
  return warnings;
}
```

```ts
import type { CheckResult, DefectClass } from "./types";

// Mirrors the checks in submit_inspection so the form can list and link
// every gap before the user presses Submit.

export type ReadinessInput = {
  items: { id: number; text: string }[];
  checks: Record<number, { result: CheckResult | null; comment: string }>;
  characteristics: { id: number; name: string }[];
  readings: Record<number, number[]>;
  defects: { defectClass: DefectClass; found: number | null }[];
  sampleSize: number;
};

export type Missing = { anchor: string; message: string };

const cap = (s: string) => s.charAt(0).toUpperCase() + s.slice(1);

export function missingForSubmit(input: ReadinessInput): Missing[] {
  const missing: Missing[] = [];

  for (const item of input.items) {
    const check = input.checks[item.id];
    if (!check?.result) {
      missing.push({ anchor: `item-${item.id}`, message: `Answer: ${item.text}` });
    } else if (check.result === "ng" && check.comment.trim() === "") {
      missing.push({ anchor: `item-${item.id}`, message: `Add a comment for NG: ${item.text}` });
    }
  }

  for (const c of input.characteristics) {
    const count = input.readings[c.id]?.length ?? 0;
    if (count === 0) {
      missing.push({ anchor: `dim-${c.id}`, message: `Enter at least one reading: ${c.name}` });
    } else if (count > input.sampleSize) {
      missing.push({
        anchor: `dim-${c.id}`,
        message: `${c.name} has ${count} readings but the sample size is ${input.sampleSize}`,
      });
    }
  }

  for (const d of input.defects) {
    if (d.found === null) {
      missing.push({ anchor: `defect-${d.defectClass}`, message: `Enter the number of ${d.defectClass} defects (0 if none)` });
    } else if (d.found > input.sampleSize) {
      missing.push({
        anchor: `defect-${d.defectClass}`,
        message: `${cap(d.defectClass)} defects (${d.found}) cannot be more than the sample size (${input.sampleSize})`,
      });
    }
  }
  return missing;
}
```

```ts
import type { Disposition } from "./types";

export type LotRow = {
  supplierId: number;
  supplierName: string;
  disposition: Disposition;
  unitsInspected: number;
  defectiveFound: number;
  receivedAt: string;
  approvedAt: string;
};

export type Metrics = {
  lots: number;
  accepted: number;
  rejected: number;
  lar: number | null; // % of lots accepted; concessions count as NOT accepted
  ppm: number | null; // defective units found per million units inspected
  medianDecisionHours: number | null; // receipt -> QA decision
};

const HOUR = 3_600_000;

function median(values: number[]): number | null {
  if (values.length === 0) return null;
  const s = [...values].sort((a, b) => a - b);
  const mid = Math.floor(s.length / 2);
  return s.length % 2 ? s[mid] : (s[mid - 1] + s[mid]) / 2;
}

export function computeMetrics(rows: LotRow[]): Metrics {
  const lots = rows.length;
  const accepted = rows.filter((r) => r.disposition === "accept").length;
  const rejected = rows.filter((r) => r.disposition === "reject").length;
  const units = rows.reduce((sum, r) => sum + r.unitsInspected, 0);
  const defective = rows.reduce((sum, r) => sum + r.defectiveFound, 0);
  const hours = rows.map((r) => (Date.parse(r.approvedAt) - Date.parse(r.receivedAt)) / HOUR);
  const med = median(hours);
  return {
    lots,
    accepted,
    rejected,
    lar: lots ? Math.round((accepted / lots) * 1000) / 10 : null,
    ppm: units ? Math.round((defective / units) * 1_000_000) : null,
    medianDecisionHours: med === null ? null : Math.round(med * 10) / 10,
  };
}

export function supplierBreakdown(rows: LotRow[]) {
  const groups = new Map<number, LotRow[]>();
  for (const r of rows) groups.set(r.supplierId, [...(groups.get(r.supplierId) ?? []), r]);
  return [...groups.entries()]
    .map(([supplierId, list]) => ({ supplierId, supplierName: list[0].supplierName, ...computeMetrics(list) }))
    .sort((a, b) => b.lots - a.lots || a.supplierName.localeCompare(b.supplierName));
}

export function ncrAgeDays(createdAt: string, closedAt: string | null, now: Date): number {
  const end = closedAt ? Date.parse(closedAt) : now.getTime();
  return Math.floor((end - Date.parse(createdAt)) / (24 * HOUR));
}
```

```ts
// CSV that opens cleanly in Excel. Cells starting with = + - @ (except plain
// numbers) are prefixed with ' so Excel never runs them as formulas.

function cell(value: unknown): string {
  if (value === null || value === undefined) return "";
  let s = typeof value === "object" ? JSON.stringify(value) : String(value);
  if (typeof value !== "number" && /^[=+\-@\t\r]/.test(s)) s = `'${s}`;
  return /[",\r\n]/.test(s) ? `"${s.replace(/"/g, '""')}"` : s;
}

export function toCsv(rows: Record<string, unknown>[], columns: string[]): string {
  const lines = [columns.map(cell).join(",")];
  for (const row of rows) lines.push(columns.map((c) => cell(row[c])).join(","));
  return lines.join("\r\n") + "\r\n";
}
```

```ts
export type BandInput = { lotMin: number; lotMax: number | null; sampleNormal: number | null; sampleTightened: number | null };

// Same coverage rules the database relies on in sample_size_for: every lot
// size from 1 upwards must fall in exactly one band.
export function validateBands(bands: BandInput[]): string[] {
  if (bands.length === 0) return ["Add at least one band."];
  const errors: string[] = [];
  const sorted = [...bands].sort((a, b) => a.lotMin - b.lotMin);
  if (sorted[0].lotMin !== 1) errors.push("The first band must start at 1.");
  sorted.forEach((band, i) => {
    const n = i + 1;
    if (band.lotMax !== null && band.lotMax < band.lotMin) errors.push(`Band ${n}: 'to' is smaller than 'from'.`);
    if (band.sampleNormal !== null && band.sampleTightened !== null && band.sampleTightened < band.sampleNormal) {
      errors.push(`Band ${n}: tightened sample (${band.sampleTightened}) must be at least the normal sample (${band.sampleNormal}).`);
    }
    const next = sorted[i + 1];
    if (!next) return;
    if (band.lotMax === null) {
      errors.push(`Band ${n} has no upper limit, so it must be the last band.`);
    } else if (next.lotMin > band.lotMax + 1) {
      errors.push(`Gap: no band covers lot sizes ${band.lotMax + 1} to ${next.lotMin - 1}.`);
    } else if (next.lotMin <= band.lotMax) {
      errors.push(`Overlap: lot sizes ${next.lotMin} to ${band.lotMax} are in two bands.`);
    }
  });
  if (sorted[sorted.length - 1].lotMax !== null) errors.push("The last band must have no upper limit (leave 'to' empty).");
  return errors;
}
```

```ts
import { cache } from "react";
import { redirect } from "next/navigation";
import { createClient, getCurrentUser } from "@/lib/supabase/server";
import type { Role } from "@/lib/iqc/types";

export type Profile = { id: string; email: string; fullName: string; role: Role; active: boolean };

// One profile lookup per request, shared by the layout and the page.
export const getProfile = cache(async (): Promise<Profile | null> => {
  const supabase = await createClient();
  const user = await getCurrentUser(supabase);
  if (!user) return null;
  const { data } = await supabase
    .from("profiles")
    .select("id, email, full_name, role, active")
    .eq("id", user.id)
    .maybeSingle();
  // RLS hides every row from a deactivated user, so "no profile" means "not allowed".
  if (!data || !data.active) {
    return { id: user.id, email: user.email, fullName: user.email, role: "inspector", active: false };
  }
  return { id: data.id, email: data.email, fullName: data.full_name, role: data.role, active: true };
});

export async function requireProfile(...roles: Role[]): Promise<Profile> {
  const profile = await getProfile();
  if (!profile) redirect("/login");
  if (!profile.active) redirect("/auth/signout?reason=deactivated");
  if (roles.length > 0 && !roles.includes(profile.role)) redirect("/?denied=1");
  return profile;
}
```

```ts
"use server";

import { revalidatePath } from "next/cache";
import { requireProfile } from "@/lib/auth";
import { createClient } from "@/lib/supabase/server";
import { firstError, partSchema, supplierSchema } from "@/lib/iqc/master-schemas";

export type FormState = { error?: string; ok?: string };

const DUPLICATE = "23505";

export async function saveSupplier(_prev: FormState, fd: FormData): Promise<FormState> {
  await requireProfile("qa");
  const parsed = supplierSchema.safeParse({
    id: fd.get("id") || undefined,
    code: fd.get("code") ?? "",
    name: fd.get("name") ?? "",
    status: fd.get("status"),
    email: fd.get("email") ?? "",
    active: fd.get("active") === "on",
  });
  if (!parsed.success) return { error: firstError(parsed.error.issues) };
  const { id, ...row } = parsed.data;
  const supabase = await createClient();
  const { error } = id
    ? await supabase.from("suppliers").update(row).eq("id", id)
    : await supabase.from("suppliers").insert(row);
  if (error) return { error: error.code === DUPLICATE ? "That supplier code already exists." : error.message };
  revalidatePath("/master/suppliers");
  return { ok: id ? "Supplier updated." : "Supplier added." };
}

export async function savePart(_prev: FormState, fd: FormData): Promise<FormState> {
  await requireProfile("qa");
  const parsed = partSchema.safeParse({
    id: fd.get("id") || undefined,
    partNo: fd.get("partNo") ?? "",
    name: fd.get("name") ?? "",
    category: fd.get("category") ?? "",
    drawingNo: fd.get("drawingNo") ?? "",
    drawingRev: fd.get("drawingRev") ?? "",
    regulated: fd.get("regulated") === "on",
    templateId: fd.get("templateId") ?? "",
    inspectionType: fd.get("inspectionType"),
    active: fd.get("active") === "on",
  });
  if (!parsed.success) return { error: firstError(parsed.error.issues) };
  const p = parsed.data;
  const row = {
    part_no: p.partNo, name: p.name, category: p.category, drawing_no: p.drawingNo, drawing_rev: p.drawingRev,
    regulated: p.regulated, template_id: p.templateId, inspection_type: p.inspectionType, active: p.active,
  };
  const supabase = await createClient();
  const { error } = p.id
    ? await supabase.from("parts").update(row).eq("id", p.id)
    : await supabase.from("parts").insert(row);
  if (error) return { error: error.code === DUPLICATE ? "That part number already exists." : error.message };
  revalidatePath("/master/parts");
  return { ok: p.id ? "Part updated." : "Part added." };
}
```

`supabase/migrations/20261012000600_template_fn.sql`:

```sql
-- Saving a template always creates a NEW version; old inspections keep theirs.
create function public.create_template_version(
  p_template_id bigint, p_name text, p_items jsonb, p_chars jsonb
) returns bigint language plpgsql security invoker set search_path = '' as $$
declare
  v_template bigint := p_template_id;
  v_version int;
  v_id bigint;
begin
  if not public.has_role('qa') then raise exception 'Only QA can edit templates.' using errcode = '42501'; end if;
  if jsonb_array_length(coalesce(p_items, '[]'::jsonb)) = 0 then
    raise exception 'A template needs at least one checklist item.';
  end if;
  if v_template is null then
    insert into public.templates (name) values (trim(p_name)) returning id into v_template;
  end if;
  select coalesce(max(version), 0) + 1 into v_version from public.template_versions where template_id = v_template;
  insert into public.template_versions (template_id, version) values (v_template, v_version) returning id into v_id;

  insert into public.template_items (version_id, section, position, text)
  select v_id, trim(x.e ->> 'section'), x.n::int, trim(x.e ->> 'text')
  from jsonb_array_elements(p_items) with ordinality as x (e, n);

  insert into public.template_characteristics (version_id, position, name, nominal, min_value, max_value, unit, defect_class)
  select v_id, x.n::int, trim(x.e ->> 'name'), (x.e ->> 'nominal')::numeric, (x.e ->> 'min')::numeric,
         (x.e ->> 'max')::numeric, coalesce(nullif(trim(x.e ->> 'unit'), ''), 'mm'),
         (x.e ->> 'defectClass')::public.defect_class
  from jsonb_array_elements(coalesce(p_chars, '[]'::jsonb)) with ordinality as x (e, n);
  return v_id;
end $$;

-- Replacing the table keeps old bands (inactive) for history and the audit log.
create function public.replace_sampling_bands(p_bands jsonb) returns void
language plpgsql security invoker set search_path = '' as $$
begin
  if not public.has_role('qa') then raise exception 'Only QA can change the sampling table.' using errcode = '42501'; end if;
  update public.sampling_bands set active = false where active and plan_source = 'KHIND';
```

```ts
"use server";

import { revalidatePath } from "next/cache";
import { requireProfile } from "@/lib/auth";
import { createClient } from "@/lib/supabase/server";
import { validateBands } from "@/lib/iqc/bands";
import { samplingSchema } from "@/lib/iqc/payload";
import { DEFECT_CLASSES } from "@/lib/iqc/types";

export async function saveSampling(raw: unknown): Promise<{ error?: string; ok?: string }> {
  await requireProfile("qa");
  const parsed = samplingSchema.safeParse(raw);
  if (!parsed.success) return { error: parsed.error.issues[0]?.message ?? "Please check the table." };
  const problems = validateBands(parsed.data.bands);
  if (problems.length) return { error: problems.join(" ") };
  const supabase = await createClient();
  const { error } = await supabase.rpc("replace_sampling_bands", { p_bands: parsed.data.bands });
  if (error) return { error: error.message };
  for (const cls of DEFECT_CLASSES) {
    const { error: e } = await supabase
      .from("sampling_acceptance")
      .upsert({ plan_source: "KHIND", defect_class: cls, ac: parsed.data.acceptance[cls] });
    if (e) return { error: e.message };
  }
  revalidatePath("/master/sampling");
  return { ok: "Sampling table saved. New inspections use it straight away." };
}
```

```ts
"use server";

import { revalidatePath } from "next/cache";
import { z } from "zod";
import { requireProfile } from "@/lib/auth";
import { createClient } from "@/lib/supabase/server";
import type { FormState } from "../../master/actions";

const schema = z.object({
  id: z.uuid(),
  fullName: z.string().trim().min(1, "Name is required.").max(80),
  role: z.enum(["inspector", "qa", "purchasing", "management", "admin"]),
  active: z.boolean(),
});

export async function updateUser(_prev: FormState, fd: FormData): Promise<FormState> {
  const me = await requireProfile("admin");
  const parsed = schema.safeParse({
    id: fd.get("id"), fullName: fd.get("fullName") ?? "", role: fd.get("role"), active: fd.get("active") === "on",
  });
  if (!parsed.success) return { error: parsed.error.issues[0]?.message ?? "Please check the form." };
  if (parsed.data.id === me.id) return { error: "You can't change your own role or deactivate yourself." };
  const supabase = await createClient();
  const { data, error } = await supabase
    .from("profiles")
    .update({ full_name: parsed.data.fullName, role: parsed.data.role, active: parsed.data.active })
    .eq("id", parsed.data.id)
    .select("id");
  if (error) return { error: error.message };
  if (!data?.length) return { error: "Not saved: you may not have permission." };
  revalidatePath("/admin/users");
  return { ok: "Saved." };
}
```

```ts
import type { Disposition, InspectionStatus } from "./types";

export type ListFilters = {
  status?: InspectionStatus;
  supplierId?: number;
  disposition?: Disposition;
  from?: string;
  to?: string;
  mine?: boolean;
};

const one = (v: string | string[] | undefined) => (typeof v === "string" && v !== "" ? v : undefined);
const DATE = /^\d{4}-\d{2}-\d{2}$/;
const STATUSES = ["draft", "submitted", "returned", "approved"];
const DISPOSITIONS = ["accept", "concession", "sort", "reject"];

// Bad or missing filter values are ignored, never an error page.
export function parseListFilters(sp: Record<string, string | string[] | undefined>): ListFilters {
  const f: ListFilters = {};
  const status = one(sp.status);
  if (status && STATUSES.includes(status)) f.status = status as InspectionStatus;
  const supplier = one(sp.supplier);
  if (supplier && /^\d+$/.test(supplier)) f.supplierId = Number(supplier);
  const disposition = one(sp.disposition);
  if (disposition && DISPOSITIONS.includes(disposition)) f.disposition = disposition as Disposition;
  const from = one(sp.from);
  if (from && DATE.test(from)) f.from = from;
  const to = one(sp.to);
  if (to && DATE.test(to)) f.to = to;
  if (one(sp.mine) === "1") f.mine = true;
  return f;
}
```

```ts
export async function saveDraft(id: number, raw: unknown): Promise<SaveResult> {
  await requireProfile("inspector", "qa");
  const parsed = draftSchema.safeParse(raw);
  if (!parsed.success) return { ok: false, error: `Some values are invalid (${parsed.error.issues[0]?.path.join(".")}).` };
  const d = parsed.data;
  const supabase = await createClient();

  const { data: updated, error: headerError } = await supabase
    .from("inspections")
    .update({
      po_no: d.header.poNo || null, do_no: d.header.doNo || null, lot_no: d.header.lotNo || null,
      qty_received: d.header.qtyReceived, received_at: d.header.receivedAt,
      instrument: d.header.instrument || null, section_notes: d.sectionNotes,
    })
    .eq("id", id)
    .select("sample_size, template_version_id")
    .maybeSingle();
  if (headerError) return { ok: false, error: headerError.message };
  if (!updated) return { ok: false, error: NOT_EDITABLE }; // RLS: not the owner, or no longer draft/returned

  if (d.checks.length) {
    const { error } = await supabase.from("inspection_checks").upsert(
      d.checks.map((c) => ({ inspection_id: id, item_id: c.itemId, result: c.result, comment: c.comment || null })),
    );
    if (error) return { ok: false, error: error.message };
  }

  if (d.readings.length) {
    const { data: limits, error: limitsError } = await supabase
      .from("template_characteristics")
      .select("id, min_value, max_value")
      .eq("version_id", updated.template_version_id);
    if (limitsError) return { ok: false, error: limitsError.message };
    const byId = new Map((limits ?? []).map((l) => [l.id, l]));
    const rows = d.readings
      .filter((r) => byId.has(r.characteristicId))
      .map((r) => {
        const l = byId.get(r.characteristicId)!;
        const min = l.min_value === null ? null : Number(l.min_value);
        const max = l.max_value === null ? null : Number(l.max_value);
        return { inspection_id: id, characteristic_id: r.characteristicId, readings: r.values, result: measurementResult(r.values, min, max) };
      });
    const { error } = await supabase.from("inspection_measurements").upsert(rows);
    if (error) return { ok: false, error: error.message };
  }

  const defectResults = await Promise.all(
    d.defects.map((x) =>
      supabase.from("inspection_defects")
        .update({ found: x.found, description: x.description || null })
        .eq("inspection_id", id).eq("defect_class", x.defectClass),
    ),
  );
  const defectError = defectResults.find((r) => r.error)?.error;
  if (defectError) return { ok: false, error: defectError.message };

  return { ok: true, savedAt: new Date().toISOString(), sampleSize: updated.sample_size };
}
```

```ts
// Runs in the browser only. Tries smaller sizes and lower JPEG quality
// until the photo fits the 200 KB limit (Supabase Free storage is small).
const SIZES = [1600, 1280, 1024, 800];
const QUALITIES = [0.8, 0.7, 0.6, 0.5];

export async function compressImage(file: File, maxBytes = 204_800): Promise<File> {
  const bitmap = await createImageBitmap(file);
  try {
    for (const size of SIZES) {
      const scale = Math.min(1, size / Math.max(bitmap.width, bitmap.height));
      const canvas = document.createElement("canvas");
      canvas.width = Math.round(bitmap.width * scale);
      canvas.height = Math.round(bitmap.height * scale);
      canvas.getContext("2d")!.drawImage(bitmap, 0, 0, canvas.width, canvas.height);
      for (const q of QUALITIES) {
        const blob = await new Promise<Blob | null>((resolve) => canvas.toBlob(resolve, "image/jpeg", q));
        if (blob && blob.size <= maxBytes) return new File([blob], "photo.jpg", { type: "image/jpeg" });
      }
    }
  } finally {
    bitmap.close();
  }
  throw new Error("Could not shrink this photo below 200 KB. Try a closer, simpler shot.");
}
```

```ts
"use server";

import { revalidatePath } from "next/cache";
import { requireProfile } from "@/lib/auth";
import { createClient } from "@/lib/supabase/server";
import { NOT_EDITABLE } from "@/lib/iqc/messages";
import { photoAllowed } from "@/lib/iqc/photos";
import { lotVerdict } from "@/lib/iqc/verdict";

const BUCKET = "inspection-photos";

export async function uploadPhoto(fd: FormData): Promise<{ error?: string }> {
  await requireProfile("inspector", "qa");
  const inspectionId = Number(fd.get("inspectionId"));
  const itemRaw = fd.get("itemId");
  const itemId = itemRaw ? Number(itemRaw) : null;
  const file = fd.get("file");
  if (!(file instanceof File)) return { error: "No photo received." };
  if (!Number.isInteger(inspectionId) || inspectionId < 1 || (itemId !== null && !Number.isInteger(itemId))) {
    return { error: "Invalid request." };
  }

  const supabase = await createClient();
  const [check, defects, acceptance, atts] = await Promise.all([
    itemId
      ? supabase.from("inspection_checks").select("result").eq("inspection_id", inspectionId).eq("item_id", itemId).maybeSingle()
      : Promise.resolve({ data: null, error: null }),
    supabase.from("inspection_defects").select("defect_class, found, ac").eq("inspection_id", inspectionId),
    supabase.from("sampling_acceptance").select("defect_class, ac").eq("plan_source", "KHIND"),
    supabase.from("attachments").select("item_id").eq("inspection_id", inspectionId),
  ]);
  const acNow = new Map((acceptance.data ?? []).map((a) => [a.defect_class, a.ac]));
  const verdict = lotVerdict(
    (defects.data ?? []).map((d) => ({ defectClass: d.defect_class, found: d.found, ac: d.ac ?? acNow.get(d.defect_class) ?? 0 })),
  );
  const reason = photoAllowed({
    itemResult: check.data?.result ?? null,
    lotVerdict: verdict,
    forItem: itemId !== null,
    countForItem: (atts.data ?? []).filter((a) => a.item_id === itemId).length,
    countTotal: (atts.data ?? []).length,
    bytes: file.size,
    mime: file.type,
  });
  if (reason) return { error: reason };

  const path = `${inspectionId}/${crypto.randomUUID()}.jpg`;
  const { error: uploadError } = await supabase.storage.from(BUCKET).upload(path, file, { contentType: file.type });
  if (uploadError) return { error: /row-level|policy/i.test(uploadError.message) ? NOT_EDITABLE : uploadError.message };
  const { error: insertError } = await supabase
    .from("attachments")
    .insert({ inspection_id: inspectionId, item_id: itemId, storage_path: path, bytes: file.size });
  if (insertError) {
    await supabase.storage.from(BUCKET).remove([path]);
    return { error: insertError.message };
  }
  revalidatePath(`/inspections/${inspectionId}`);
  return {};
}

export async function deletePhoto(attachmentId: number): Promise<{ error?: string }> {
  await requireProfile("inspector", "qa");
  const supabase = await createClient();
  const { data, error } = await supabase
    .from("attachments").delete().eq("id", attachmentId).select("storage_path, inspection_id");
  if (error) return { error: error.message };
  if (!data?.length) return { error: NOT_EDITABLE };
  await supabase.storage.from(BUCKET).remove([data[0].storage_path]);
  revalidatePath(`/inspections/${data[0].inspection_id}`);
  return {};
}
```

```ts
const TABLES: Record<string, string> = {
  inspection_checks: "Checklist", inspection_measurements: "Dimension", inspection_defects: "Defects",
  attachments: "Photo", ncrs: "NCR", sampling_bands: "Sampling band", sampling_acceptance: "Acceptance",
  suppliers: "Supplier", parts: "Part", templates: "Template", template_versions: "Template version", profiles: "User",
};
const FIELDS: Record<string, string> = {
  status: "Status", lot_no: "Lot no.", po_no: "PO no.", do_no: "DO no.", qty_received: "Quantity", received_at: "Received at",
  sample_size: "Sample size", sample_override_reason: "Override reason", stage: "Stage", disposition: "Disposition",
  verdict: "Verdict", approver_id: "Approver", approved_at: "Approved at", submitted_at: "Submitted at",
  return_comment: "Return comment", concession_reason: "Concession reason", reopen_reason: "Reopen reason",
  result: "Result", comment: "Comment", readings: "Readings", found: "Found", description: "Description",
  scar_no: "SCAR no.", rma_no: "RMA no.", supplier_response: "Supplier response", closed_at: "Closed at",
  instrument: "Instrument", section_notes: "Section notes", role: "Role", active: "Active",
};

const show = (v: unknown) => {
  if (v === null || v === undefined || v === "") return "(empty)";
  const s = typeof v === "object" ? JSON.stringify(v) : String(v);
  return s.length > 60 ? `${s.slice(0, 57)}…` : s;
};

export function describeChange(e: { table_name: string; action: string; changes: Record<string, unknown> }): string[] {
  if (e.table_name === "inspections" && e.action === "insert") return [`Inspection ${show(e.changes.number)} created`];
  const prefix = e.table_name === "inspections" ? "" : `${TABLES[e.table_name] ?? e.table_name}: `;
  if (e.action === "insert") return [`${TABLES[e.table_name] ?? e.table_name} added`];
  if (e.action === "delete") return [`${TABLES[e.table_name] ?? e.table_name} removed`];
  return Object.entries(e.changes).map(([field, pair]) => {
    const [from, to] = Array.isArray(pair) ? pair : [undefined, pair];
    return `${prefix}${FIELDS[field] ?? field}: ${show(from)} → ${show(to)}`;
  });
}
```

```ts
import { revalidatePath } from "next/cache";
import { requireProfile } from "@/lib/auth";
import { createClient } from "@/lib/supabase/server";
import { ncrUpdateSchema } from "@/lib/iqc/payload";
import type { FormState } from "../master/actions";

export async function updateNcr(_prev: FormState, fd: FormData): Promise<FormState> {
  await requireProfile("purchasing", "qa");
  const parsed = ncrUpdateSchema.safeParse({
    id: fd.get("id"), scarNo: fd.get("scarNo") ?? "", rmaNo: fd.get("rmaNo") ?? "",
    supplierResponse: fd.get("supplierResponse") ?? "", status: fd.get("status"),
  });
  if (!parsed.success) return { error: parsed.error.issues[0]?.message ?? "Please check the form." };
  const n = parsed.data;
  const supabase = await createClient();
  const { data: current } = await supabase.from("ncrs").select("closed_at").eq("id", n.id).maybeSingle();
  const { data, error } = await supabase
    .from("ncrs")
    .update({
      scar_no: n.scarNo, rma_no: n.rmaNo, supplier_response: n.supplierResponse, status: n.status,
      closed_at: n.status === "closed" ? current?.closed_at ?? new Date().toISOString() : null,
    })
    .eq("id", n.id)
    .select("id");
  if (error) return { error: error.message };
  if (!data?.length) return { error: "Not saved: you may not have permission." };
  revalidatePath("/ncrs");
  revalidatePath(`/ncrs/${n.id}`);
  return { ok: "NCR saved." };
```

```ts
import ExcelJS from "exceljs";
import type { InspectionBundle } from "./load";
import { DISPOSITION_LABELS } from "./types";
import { measurementResult } from "./verdict";

const RESULT = { ok: "OK", ng: "NG", na: "N/A" } as const;
const when = (iso: string | null) => (iso ? new Date(iso).toLocaleString("en-MY", { timeZone: "Asia/Kuala_Lumpur" }) : "");

export function buildInspectionWorkbook(b: InspectionBundle): ExcelJS.Workbook {
  const wb = new ExcelJS.Workbook();
  wb.creator = "KHIND IQC";

  const s = wb.addWorksheet("Summary");
  s.columns = [{ width: 32 }, { width: 50 }];
  s.addRows([
    ["Incoming Quality Inspection", ""],
    ["Inspection no.", b.number],
    ["Status", b.status],
    ["Supplier", `${b.supplier.code} · ${b.supplier.name}`],
    ["Part", `${b.part.partNo} · ${b.part.name}`],
    ["Drawing", [b.part.drawingNo, b.part.drawingRev].filter(Boolean).join(" rev ")],
    ["PO no.", b.poNo], ["DO / invoice no.", b.doNo], ["Lot / batch no.", b.lotNo],
    ["Quantity received", b.qtyReceived], ["Received at", when(b.receivedAt)],
    ["Sample size", b.sampleSize], ["Sample override reason", b.sampleOverrideReason ?? ""], ["Stage", b.stage],
    ["Template", `${b.templateName} v${b.templateVersion}`], ["Instrument(s)", b.instrument],
    ["Inspector", b.inspector.name], ["Submitted at", when(b.submittedAt)],
    ["System verdict", b.verdict ?? ""], ["Disposition", b.disposition ? DISPOSITION_LABELS[b.disposition] : ""],
    ["Concession reason", b.concessionReason ?? ""],
    ["Approved by", b.approver?.name ?? ""], ["Approved at", when(b.approvedAt)],
    ["NCR", b.ncr?.number ?? ""],
  ]);
  s.getRow(1).font = { bold: true, size: 14 };

  const c = wb.addWorksheet("Checklist");
  c.columns = [{ header: "Section", width: 30 }, { header: "Check", width: 70 }, { header: "Result", width: 10 }, { header: "Comment", width: 40 }];
  for (const item of b.items) {
    const check = b.checks[item.id];
    c.addRow([item.section, item.text, check ? RESULT[check.result] : "", check?.comment ?? ""]);
  }
  for (const [section, note] of Object.entries(b.sectionNotes)) if (note) c.addRow([section, "Section notes", "", note]);

  const d = wb.addWorksheet("Dimensional");
  d.columns = [
    { header: "Characteristic", width: 30 }, { header: "Nominal", width: 10 }, { header: "Min", width: 10 },
    { header: "Max", width: 10 }, { header: "Unit", width: 8 }, { header: "Readings", width: 40 }, { header: "Result", width: 10 },
  ];
  for (const ch of b.characteristics) {
    const values = b.readings[ch.id] ?? [];
    const r = measurementResult(values, ch.min, ch.max);
    d.addRow([ch.name, ch.nominal, ch.min, ch.max, ch.unit, values.join(", "), r ? r.toUpperCase() : ""]);

  for (const ws of [c, d, x]) ws.getRow(1).font = { bold: true };
  return wb;
}
```

```ts
import type { NextRequest } from "next/server";
import { getProfile } from "@/lib/auth";
import { createClient } from "@/lib/supabase/server";
import { toCsv } from "@/lib/iqc/csv";
import { parseListFilters } from "@/lib/iqc/filters";

export async function GET(request: NextRequest) {
  const profile = await getProfile();
  if (!profile) return new Response("Sign in first.", { status: 401 });
  if (!profile.active) return new Response("Account deactivated.", { status: 403 });
  const f = parseListFilters(Object.fromEntries(request.nextUrl.searchParams));
  const supabase = await createClient();
  let q = supabase
    .from("inspections")
    .select(`number, status, verdict, disposition, po_no, do_no, lot_no, qty_received, sample_size, received_at,
      submitted_at, approved_at, supplier:suppliers(code, name), part:parts(part_no, name),
      inspector:profiles!inspections_inspector_id_fkey(full_name), approver:profiles!inspections_approver_id_fkey(full_name)`)
    .order("received_at", { ascending: false })
    .limit(5000);
  if (f.status) q = q.eq("status", f.status);
  if (f.supplierId) q = q.eq("supplier_id", f.supplierId);
  if (f.disposition) q = q.eq("disposition", f.disposition);
  if (f.from) q = q.gte("received_at", `${f.from}T00:00:00+08:00`);
  if (f.to) q = q.lte("received_at", `${f.to}T23:59:59.999+08:00`);
  if (f.mine) q = q.eq("inspector_id", profile.id);
  const { data, error } = await q;
  if (error) return new Response(error.message, { status: 500 });
  const rows = data.map((r) => ({
    number: r.number, status: r.status, verdict: r.verdict, disposition: r.disposition,
    supplier_code: r.supplier?.code, supplier: r.supplier?.name, part_no: r.part?.part_no, part: r.part?.name,
    po_no: r.po_no, do_no: r.do_no, lot_no: r.lot_no, qty_received: r.qty_received, sample_size: r.sample_size,
    received_at: r.received_at, submitted_at: r.submitted_at, approved_at: r.approved_at,
    inspector: r.inspector?.full_name, approver: r.approver?.full_name,
  }));
  const columns = ["number", "status", "verdict", "disposition", "supplier_code", "supplier", "part_no", "part", "po_no", "do_no",
    "lot_no", "qty_received", "sample_size", "received_at", "submitted_at", "approved_at", "inspector", "approver"];
  const today = new Date().toISOString().slice(0, 10);
  return new Response("﻿" + toCsv(rows, columns), {
    headers: {
      "Content-Type": "text/csv; charset=utf-8",
      "Content-Disposition": `attachment; filename="inspections-${today}.csv"`,
      "Cache-Control": "no-store",
    },
  });
}
```

```sql
-- How close are we to the Supabase Free limits? (admin and QA only)
create function public.usage_stats()
returns table (db_bytes bigint, photo_bytes bigint, photo_count bigint)
language sql stable security definer set search_path = '' as $$
  select pg_database_size(current_database()),
         coalesce((select sum((o.metadata ->> 'size')::bigint) from storage.objects o where o.bucket_id = 'inspection-photos'), 0),
         (select count(*) from storage.objects o where o.bucket_id = 'inspection-photos')
  where public.has_role('admin', 'qa')
$$;
revoke execute on function public.usage_stats from public, anon;
grant execute on function public.usage_stats to authenticated;
```

```ts
import { strToU8, zipSync } from "fflate";
import { getProfile } from "@/lib/auth";
import { createClient } from "@/lib/supabase/server";
import { toCsv } from "@/lib/iqc/csv";

// Table -> column to page by (stable order).
const TABLES: Record<string, string> = {
  profiles: "id", suppliers: "id", parts: "id", templates: "id", template_versions: "id", template_items: "id",
  template_characteristics: "id", sampling_bands: "id", sampling_acceptance: "defect_class", inspections: "id",
  inspection_checks: "inspection_id", inspection_measurements: "inspection_id", inspection_defects: "inspection_id",
  attachments: "id", ncrs: "id", audit_log: "id", backups: "id",
};
const PAGE = 1000;

export async function GET() {
  const profile = await getProfile();
  if (!profile) return new Response("Sign in first.", { status: 401 });
  if (!profile.active || profile.role !== "admin") return new Response("Admins only.", { status: 403 });

  const supabase = await createClient();
  const files: Record<string, Uint8Array> = {};
  let total = 0;
  for (const [table, orderBy] of Object.entries(TABLES)) {
    const rows: Record<string, unknown>[] = [];
    for (let from = 0; ; from += PAGE) {
      const { data, error } = await supabase
        .from(table as never)
        .select("*")
        .order(orderBy as never)
        .range(from, from + PAGE - 1);
      if (error) return new Response(`Export failed on ${table}: ${error.message}`, { status: 500 });
      rows.push(...(data as Record<string, unknown>[]));
      if (data.length < PAGE) break;
    }
    total += rows.length;
    const columns = rows.length ? Object.keys(rows[0]) : [];
    files[`${table}.csv`] = strToU8(toCsv(rows, columns));
  }

  const today = new Date().toISOString().slice(0, 10);
  files["README.txt"] = strToU8(
    [
      `KHIND IQC backup ${today} (${total} rows).`,
      "One CSV per table. Photos are NOT inside this file: they stay in Supabase Storage (bucket inspection-photos);",
      "attachments.csv lists their paths. Keep the latest 12 weekly backups in the QA OneDrive folder.",
    ].join("\r\n"),
  );

  const { error: logError } = await supabase.from("backups").insert({ row_count: total, note: "Export all data" });
  if (logError) return new Response(`Could not record the backup: ${logError.message}`, { status: 500 });

  return new Response(Buffer.from(zipSync(files)), {
    headers: {
      "Content-Type": "application/zip",
      "Content-Disposition": `attachment; filename="khind-iqc-backup-${today}.zip"`,
      "Cache-Control": "no-store",
    },
  });
}
```

- [ ] **Step 2: Implement `lib/iqc/periods.ts`**

```ts
const KL = 8 * 3_600_000;
const DAY = 86_400_000;
const DATE = /^\d{4}-\d{2}-\d{2}$/;

export type Period = {
  key: "this-month" | "last-month" | "90d" | "custom";
  fromIso: string; toIso: string; // UTC instants, toIso exclusive
  fromDate: string; toDate: string; // Malaysia dates, inclusive
  label: string;
};

const klMidnight = (y: number, m: number, d: number) => new Date(Date.UTC(y, m, d) - KL);
const klDate = (t: Date) => new Date(t.getTime() + KL).toISOString().slice(0, 10);

function make(key: Period["key"], from: Date, toExclusive: Date, label: string): Period {
  return {
    key, fromIso: from.toISOString(), toIso: toExclusive.toISOString(),
    fromDate: klDate(from), toDate: klDate(new Date(toExclusive.getTime() - 1)), label,
  };
}

const monthLabel = (y: number, m: number) =>
  new Date(Date.UTC(y, m, 15)).toLocaleString("en-MY", { month: "long", year: "numeric", timeZone: "UTC" });

export function resolvePeriod(sp: { period?: string; from?: string; to?: string }, now: Date): Period {
  const local = new Date(now.getTime() + KL);
  const y = local.getUTCFullYear();
  const m = local.getUTCMonth();
  const d = local.getUTCDate();

  if (sp.period === "last-month") return make("last-month", klMidnight(y, m - 1, 1), klMidnight(y, m, 1), monthLabel(y, m - 1));
  if (sp.period === "90d") return make("90d", klMidnight(y, m, d - 89), klMidnight(y, m, d + 1), "Last 90 days");
  if (sp.period === "custom" && sp.from && sp.to && DATE.test(sp.from) && DATE.test(sp.to) && sp.from <= sp.to) {
    const [fy, fm, fd] = sp.from.split("-").map(Number);
    const [ty, tm, td] = sp.to.split("-").map(Number);
    return make("custom", klMidnight(fy, fm - 1, fd), klMidnight(ty, tm - 1, td + 1), `${sp.from} to ${sp.to}`);
  }
  return make("this-month", klMidnight(y, m, 1), klMidnight(y, m + 1, 1), monthLabel(y, m));
}
```
