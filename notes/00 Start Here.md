# 00 Start Here

Welcome! In this course you build a real, live web app — **KHIND Todo** — from a blank page to a public URL, using four free tools and Claude Code as your coding partner.

## The four tools and their jobs

| Tool | Think of it as… | Used in |
|---|---|---|
| **Obsidian** | Your project notebook | Every lesson — you're reading it now |
| **GitHub** | The safe where code and its history live | [[L3 GitHub - repo and first push]] onward |
| **Supabase** | The database + login system | [[L5 Supabase - database and login]] |
| **Vercel** | The web host that puts the app online | [[L7 Vercel - go live]] |

```
Obsidian notes ─┐
                ├─► GitHub repo ──(every push)──► Vercel builds + hosts ──► live URL
   app code ────┘                                      │
                                                       ▼
                                        Supabase (login + todos table)
```

## How to use these notes

1. Open this `notes` folder in Obsidian: **Open folder as vault** → pick `khind-todo/notes`.
2. Do the lessons in order. Each one has: **Goal → Steps → What you should see → If it goes wrong**.
3. Lines starting with 💬 are prompts you type into Claude Code.
4. Write what happened to you in [[Log]] — mistakes are the best lessons.
